# 🌐 W3C Java Tutorial 

A full-stack educational web application inspired by [W3Schools](https://www.w3schools.com/), built using **Node.js**, **Express.js**, and **EJS templating**. This project showcases a basic Java tutorial interface with authentication functionality and a structured layout.

---

## 🚀 Features

- ✅ Home Page with Java Tutorials Sidebar
- ✅ Detailed Pages: Java Intro, Data Types, Variables, Object, Classes, Inheritance, Polymorphism, Abstraction, Encapsulation
- ✅ Authentication: Register & Login (with sessions)
- ✅ Global Layout using `layout.ejs`
- ✅ Dynamic Routing with `express.Router()`
- ✅ Responsive Design using CSS (mobile-friendly)
- ✅ Clean Folder Structure for scalability
